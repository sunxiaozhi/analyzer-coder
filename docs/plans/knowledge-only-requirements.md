# 纯知识库项目最小改造需求

状态：已按本范围实施，验证记录见设计文档。日期：2026-10-11。

## 目标与范围

创建项目时允许不导入代码，创建后直接维护知识卡、发布、检索和问答。保留现有代码项目流程、项目权限、附件存储下载、知识修订与问答历史。

不包含 PDF/Word 等附件正文解析、自动分段入库、附件全文检索、外部知识源同步，以及纯知识库后续接入代码。现有 Markdown 来源发现依赖仓库扫描，不纳入纯知识库入口。

## 使用流程

1. 在项目创建入口选择“仅作为知识库使用”。只填写名称（必填，最多 100 字符）和说明（可选，最多 500 字符）。无需地址、ZIP 或凭据。
2. 保存成功即成为正式项目，不留下等待代码接入的草稿。自动创建并选中 WORKSPACE 虚拟分支，进入知识管理，无需手动选择分支。
3. 创建或编辑知识卡，沿用标题、正文、标签、知识类型、附件及约束设置；知识默认在本项目内可见。
4. 保存为草稿，由有管理权限的用户确认发布。编辑已发布卡片继续生成草稿修订，重新发布后供检索使用。
5. 已发布且审核通过的知识可检索、问答并追溯引用。无需同步分支或构建代码索引。无知识时正常展示空结果；知识向量不可用时保留关键词检索。

## 界面要求

- 纯知识库标明项目用途，知识工作区保留“知识管理”和“知识问答”两个入口。项目说明和知识数量并入知识管理顶部，不再提供独立项目总览和知识检索入口。
- 知识管理使用同一个搜索框，支持“全部可见知识”“已发布知识”“草稿”范围；已发布知识调用现有检索服务并按相关度排序，保留可用的向量语义检索，其余范围按标题、正文和标签筛选可见卡片。草稿不参与已发布检索及问答。
- 旧总览、知识检索和图谱链接在纯知识库模式下转到知识管理；旧检索链接保留关键词并选择已发布范围。代码项目继续保留原有总览、联合检索和图谱入口。
- 保留分支概念，公共项目栏、项目管理、知识管理和问答范围显示 WORKSPACE 虚拟分支；虚拟分支无需代码提交、同步或代码索引，创建后自动选中。
- 隐藏代码同步、代码索引、图谱、代码关联、仓库 Markdown 来源和代码失效提示。项目设置保留名称、说明、虚拟分支及权限管理；隐藏仓库路径与代码凭据。
- 总览、检索、问答及公共项目栏不能提示“先同步代码”“先构建代码索引”。
- 既有代码项目的表单、分支隔离、索引与问答准备条件保持原有行为。

## 权限及数据行为

沿用 READ / MAINTAIN / MANAGE 和所有者规则。普通读者只能读取已发布知识；维护者可维护草稿，管理者可发布。删除沿用现有项目删除及受管附件清理机制。知识与问答上下文继续绑定账号、项目和有效期，不能跨项目或跨账号复用。

## 验收条件

1. 不提供代码或凭据即可创建正式项目，刷新后仍可选中并进入知识管理。
2. 无代码版本、代码片段、代码索引或图谱产物，仍能创建、编辑、发布知识。
3. 发布后刷新阅读上下文可检索到当前修订；问答能引用纯知识证据并保存历史。
4. 草稿、撤回及未审核知识不进入有效检索；权限和项目隔离生效。
5. 代码操作在纯知识库中不显示，直接调用代码准备接口也不能创建任务。
6. 原代码项目创建、阅读分支、检索及问答就绪校验通过回归。

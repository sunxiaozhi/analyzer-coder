# Analyzer Coder 使用手册

核对日期：2026-09-12
当前定位：最小版本的“代码 + 知识”联合检索工具。

## 1. 系统解决什么问题

开发者接入一个项目后，可以在同一个入口中搜索源码片段和项目知识，并从结果回到文件、行号或知识原文核对。系统优先提供可追溯的检索证据，不把模型生成内容当作代码事实。

最小主流程只有四步：

1. 在“项目管理”接入仓库。
2. 在“项目总览”准备当前代码快照和内容索引。
3. 在“知识库”查看或补充 Markdown 与知识卡片。
4. 在“代码与知识”输入问题，联合检索两类结果。

“问项目”和 MCP 是可选入口：前者基于检索证据生成自然语言回答，后者把相同的只读检索能力提供给编码工具。

## 2. 第一次使用

### 2.1 接入项目

进入“项目管理”，选择本地 Git、远程 Git 或 ZIP。系统把可读取的项目内容发布为受管快照，不在原仓库中编辑或提交代码。

本地路径是后端服务所在机器能读取的路径，不是浏览器所在电脑的任意路径。远程仓库是否能导入取决于网络、凭据和分支配置。

### 2.2 准备索引

选择当前项目，进入“项目总览”并点击准备操作。最小检索依赖代码快照和内容片段；向量模型、代码图谱和知识失效检查属于增强能力，缺失时仍可降级为关键词检索。

准备完成后应至少确认：

- 当前项目、分支和 Commit 正确；
- 已发布 Snapshot；
- 代码片段数大于零；
- 页面没有阻断检索的错误。

### 2.3 准备知识

进入“知识库”查看项目中的 Markdown 来源和知识卡片。具有维护权限的用户可以补充项目约束、架构说明和开发约定；只读用户仍可查看可见知识。

知识结果会携带状态和来源。过期、未发布或不满足检索条件的知识不会被伪装成正式规则。

### 2.4 联合检索

进入“代码与知识”，输入路径、类名、函数名、业务概念或自然语言问题。每次查询都限定在当前选择的项目内。

结果分为两类：

| 类型 | 主要来源 | 核对方式 |
| --- | --- | --- |
| 代码 | 当前 Snapshot 的文件与 `code_chunks` | 查看路径、符号、行号和原文 |
| 知识 | 可检索的知识卡片与 Markdown 来源 | 查看标题、状态、来源和正文 |

排序分数只表示相关性，不等于事实正确率。回答问题时应优先核对原始代码和知识来源。

## 3. 可选能力

### 3.1 问项目

“问项目”先检索当前项目的代码和知识，再生成带引用的回答。没有外部模型时可以使用本地证据模式；外部模型文本是辅助总结，引用才是核对依据。

### 3.2 MCP 接入

MCP 只提供 `search_project`：输入 `repositoryId`、`query` 和可选 `limit`，返回当前项目中的代码与知识结果。访问令牌继承所属账号的实时仓库 READ 权限，不允许修改代码、知识、账号或项目配置。

### 3.3 管理功能

管理员可以查看索引任务、配置模型、管理账号权限和读取审计日志。这些能力用于保障检索系统运行，不属于开发者的最小使用路径。

## 4. 数据与权限边界

| 边界 | 说明 |
| --- | --- |
| 仓库隔离 | 每个请求都按当前账号和 `repositoryId` 校验权限 |
| 版本一致性 | 代码、片段、向量和知识引用应与当前 `snapshotId` 对齐 |
| 只读代码 | 平台浏览和检索受管快照，不充当在线 IDE |
| 模型边界 | 模型输出是建议，不覆盖原始文件和知识来源 |
| 降级能力 | 向量或图谱不可用时，系统可以继续使用关键词和文件检索 |

权限从低到高为 READ、MAINTAIN、MANAGE 和 OWNER。前端隐藏按钮只用于减少误操作，最终权限以服务端校验为准。

## 5. 当前明确不做

当前版本不包含变更审查、需求影响预估、PR/MR Webhook、审查型 CI、测试或审批判定、任务结果回报，也不会自动修改或提交代码。这些能力不应出现在导航、帮助页或 MCP 工具目录中。

## 6. 常见问题

### 搜不到代码

确认已选择正确项目，项目总览存在当前 Snapshot 和代码片段。然后先用真实路径、类名或函数名做一次关键词查询。

### 只看到代码，没有知识

检查知识库是否存在可检索内容及其发布、来源状态。Markdown 文件存在不代表已经转化为正式知识卡片，但仍可作为知识来源展示。

### 向量或图谱不可用

这不会阻断最小检索。页面应明确显示降级原因，用户仍可通过关键词、路径和原文完成核对。

### 切换项目后结果变化

这是预期行为。当前项目是所有代码、知识、问答和 MCP 查询的隔离边界。

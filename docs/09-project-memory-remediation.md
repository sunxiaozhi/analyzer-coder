# 项目记忆平台整改清单

## 1. 整改目标

产品定位从“帮助人检索和阅读代码”推进为“人与智能体共享的项目记忆入口”。

当前阶段不追求一次性建设完整企业知识库，而是先打通三个最小闭环：

1. 用户进入系统后，无需先输入关键词即可看到项目整体结构和准备状态。
2. 索引对象从代码扩展到文档、规则、任务和配置，并能识别关键资产。
3. 人或 Agent 可围绕具体任务生成绑定当前快照、可追溯、可复制的 Context Pack。

## 3. 验收场景

| 场景 | 验收标准 |
| --- | --- |
| 首次进入项目 | 不输入关键词即可看到结构、状态、入口和关键资产 |
| 查看非代码资产 | README、Agent 指令、规则、任务和配置可被索引并标明类型 |
| Agent 开始任务 | 输入任务后可得到绑定 snapshot/commit 的 Markdown Context Pack |
| 人工审查 | 每条上下文均可回到文件路径和行号，能够判断证据来源 |
| 权限与边界 | 只有 READ 可见仓库可生成；生成操作不修改仓库 |

# 项目总览数据口径

项目总览服务于“代码 + 知识”联合检索的准备检查，不对代码质量、安全性、测试覆盖率或知识正确性做综合评分。

| 区域 | 数据来源 | 解释边界 |
| --- | --- | --- |
| 当前版本 | 仓库当前分支、Commit、Snapshot 与读取时间 | Snapshot 是当前检索版本的一致性标识，不是完整历史源码库 |
| 准备阶段 | 快照、内容索引、向量、图谱和知识检查任务 | 内容索引是最小检索前置条件；向量和图谱可以降级 |
| 代码片段 | 当前 Snapshot 的文件与 `code_chunks` | 数量大于零表示存在可检索片段，不代表召回一定完整 |
| 向量覆盖 | 当前模型下有效向量数 / 已索引片段数 | 100% 只表示没有缺失向量，不代表语义结果一定正确 |
| 图谱节点与关系 | 当前 Snapshot 的 CodeGraph 产物 | 属于静态分析增强，不代表运行时调用事实 |
| 知识状态 | 知识卡片的发布、来源和负责人状态 | 状态用于解释检索资格，不证明内容绝对正确 |
| 代码类型 | 文件路径、扩展名与命名规则 | 是启发式分类，不是测试覆盖率或业务架构结论 |
| 当前缺口 | 准备状态、索引错误和知识状态汇总 | 只给出可执行的准备或知识处理入口 |

页面刷新只重新读取统计；“准备项目”或阶段重试会创建后台任务。前端必须比较 profile、code-facts 与 health-overview 返回的 Snapshot，版本不一致时不应把数据拼成同一个当前状态。

工作区右上角“帮助说明”打开独立功能导航。帮助页读取当前项目的准备状态，并按“选择项目 → 准备索引 → 知识库 → 代码与知识 → 可选问答”说明使用顺序。

当前总览不展示变更审查历史，也不提供审查入口。

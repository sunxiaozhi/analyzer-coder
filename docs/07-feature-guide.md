# 功能使用指南

## 1. 登录与账号

使用初始管理员登录后先按提示修改密码。管理员在“账号管理”中创建普通账号、启停账号、重置临时密码，并为账号授予仓库的读取、维护或管理权限。会话使用 HttpOnly Cookie，修改类请求同时校验 CSRF Token；退出、改密和恢复校验会使相关会话失效。

## 2. 接入仓库

进入“仓库管理”，点击“接入仓库”：

- 本地 Git：填写白名单内的服务端绝对路径。平台只读取 Git 元数据并创建冻结快照，不修改原工作区。
- 远程 Git：填写公共 HTTPS Git 地址和可选分支。导入前拒绝内嵌凭据、本机、内网、链路本地、多播、保留地址和非 443 端口。
- GitLab：操作方式与远程 Git 相同，来源类型单独记录。
- ZIP：上传 ZIP；平台限制文件数量、单文件及总解压大小并拦截路径穿越，然后把内容固化为可追踪快照。

仓库列表可重新扫描本地来源、创建索引任务或逻辑删除仓库。版本变化后发布新快照，后续索引和图谱都绑定具体 snapshot ID。

## 3. 内容索引与任务

在仓库行点击“创建索引”。任务中心展示排队、运行、成功、失败、取消和重试状态。索引从冻结快照读取文件，跳过 `.env`、私钥、证书和常见凭据文件，生成带文件、符号、行号和内容摘要的 chunk，并写入 PostgreSQL。

任务失败时可在任务中心重试；运行中的任务可取消。服务重启后遗留的非终态任务不会永久卡在运行中。

## 4. Chunk 浏览、混合检索和问答

“代码检索”支持按文件、符号和正文关键词浏览 chunk。混合检索将关键词得分与 pgvector 的 64 维本地确定性向量合并，结果绑定当前索引版本。

“代码问答”选择单个仓库后输入问题。当前默认 provider 为 `deterministic-local`：不会向外部发送代码，回答列出相关文件、符号和行号，并在右侧展示可复核引用。没有证据时明确返回“未找到足够证据”。

## 5. CodeGraph 与影响分析

进入“图分析”，选择仓库并点击“构建/重新构建图谱”。后端把冻结快照复制到独立分析目录，运行 CodeGraph CLI，校验 `.codegraph` 后原子发布产物记录；源码快照保持不变。

输入符号名和深度后执行影响分析。页面展示受影响符号、源码位置、关系边、节点/边统计、LOW/MEDIUM/HIGH 风险以及静态分析限制。切换仓库快照后需要为新快照重新构建图谱，旧产物不会冒充当前结果。

## 6. 知识卡片

“知识沉淀”可创建业务规则、技术决策、接口约定和模块说明，状态支持草稿、发布、需要复核和归档。每次编辑都会生成新的修订，不覆盖历史。

点击“历史”可查看所有版本；“恢复为新草稿”会复制所选历史内容并生成更高版本号，原历史完整保留。普通读取只返回已发布卡片，维护权限用于创建、编辑和恢复。

## 7. 系统设置与备份清单

管理员可配置最大检索结果、排除规则、本地模型标识和备份保留天数。敏感设置在读取接口中以掩码返回。

“立即创建备份”当前生成数据库内的一致性清单和 SHA-256 摘要，覆盖账号投影、仓库投影、设置和知识卡片；“校验并恢复”校验清单完整性并使现有登录会话失效。它不是 PostgreSQL 物理备份，生产环境仍需对数据库卷和受管数据目录配置独立加密备份。

## 8. 当前外部能力边界

- 私有远程仓库当前依赖运行账户的 Git Credential Manager/系统凭据，不提供平台内明文凭据输入或回显。
- 默认问答完全本地、确定性且可引用；尚未启用外部 LLM。设置页中的外部开关默认关闭。
- CodeGraph CLI 是独立组件；未安装时内容索引、检索、问答和知识卡片仍可使用，图分析不可用。

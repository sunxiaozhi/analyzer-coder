# 使用指南

## 1. 导入并准备仓库

在“项目管理”接入 Git 或 ZIP 仓库。完成后进入“项目总览”启动准备，等待当前快照产生内容片段。没有内容索引时，联合检索无法返回代码。

## 2. 维护知识

进入“知识库”新建卡片，填写标题和正文，并尽量绑定适用路径或符号。发布后的知识才会进入正式联合检索；草稿可继续编辑但不会冒充已确认知识。

## 3. 联合检索

进入“代码与知识”，输入类名、函数名、错误信息或业务描述。结果中的 `CODE` 可打开源码，`KNOWLEDGE` 可打开知识详情。优先检查路径、行号和关联范围，而不是只看摘要。

## 4. 证据问答

“问项目”是联合检索之上的可选入口。回答应附带可打开的代码或知识引用；无外部模型时可使用本地证据模式。

## 5. MCP

在“MCP 接入”创建访问令牌并配置客户端。调用：

```json
{
  "repositoryId": "<仓库 UUID>",
  "query": "订单超时在哪里处理，有哪些相关约束？",
  "limit": 20
}
```

`search_project` 只读，实时校验仓库 READ 权限，不修改代码或知识。

## 6. 常见问题

- 搜不到代码：确认项目总览已有内容片段，先尝试真实类名或路径。
- 搜不到知识：确认知识已发布，且标题、正文或关联范围与查询有关。
- 只有关键词效果：未配置向量模型时属于正常降级，不影响基础检索。
- MCP 返回 401/403：检查令牌有效期和目标仓库 READ 权限。

# 功能使用指南

版本：v2.1
日期：2026-07-31
状态：按当前实现校准
实现基线：1.0.0 发布候选工作区

## 1. 导航与工作区

登录后默认进入“知识问答”。主菜单当前顺序为：

1. 知识问答（`/ask`）
2. 知识沉淀（`/knowledge`）
3. 图分析（`/graph`）
4. 源码检索（`/search`）
5. 仓库管理（`/repositories`）
6. 索引任务（`/indexing`）
7. 账号管理（`/accounts`，仅超级管理员）
8. 系统设置（`/settings`，仅超级管理员）

仓库型页面共用当前仓库上下文；切换仓库会影响问答、知识、图、源码检索和索引视图。当前仓库偏好保存到服务端。打开文件、知识卡片等内容会形成工作区页签，页签状态保存在当前浏览器，刷新后可恢复；最多缓存 12 个页面。

## 2. 登录与账号

使用用户名和密码登录。连续失败达到阈值后，登录页会显示算术验证码。会话通过 HttpOnly Cookie 保存，修改请求还需通过 CSRF 校验。

超级管理员可在“账号管理”中：

- 创建账号；
- 查看和筛选账号；
- 启用、停用、解锁账号；
- 重置账号密码。

重置密码会生成只展示一次的安全随机临时密码，有效 24 小时，同时撤销该账号旧会话；账号下次登录必须先完成改密。

## 3. 仓库与权限

所有已启用账号都可以创建仓库。普通账号只能看到自己拥有或被授权的仓库，超级管理员可以查看全部仓库。

### 3.1 接入方式

- 本地 Git：填写服务端允许根目录内的绝对路径；平台读取仓库并发布受管版本，不修改原目录。
- 远程 Git：填写 HTTPS 地址和分支；私有仓库选择或新建通用 Git HTTPS Token。
- GitLab：填写 HTTPS 项目克隆地址和分支，选择或新建 GitLab PAT。
- 凭据可在接入弹窗内创建、编辑和检测；Token 仅在保存时输入，之后只显示掩码。
- ZIP：上传压缩包；平台校验路径穿越、文件数量、大小和压缩比后导入。

接入过程先在 staging 准备，成功后才发布仓库和当前代码版本。失败任务不会把半成品当作可用仓库。

### 3.2 权限级别

| 权限 | 当前能力 |
| --- | --- |
| READ | 查看仓库、检索、问答、图和已发布知识 |
| MAINTAIN | READ + 同步、分析、索引及知识草稿维护 |
| MANAGE | MAINTAIN + 知识人工评审与发布、仓库配置和成员管理 |
| MANAGE | MAINTAIN + 非敏感仓库配置 |
| OWNER | MANAGE + 成员授权、凭据、所有权转移和删除 |

超级管理员拥有全局管理能力。按钮是否显示由服务端 capabilities 决定，但最终权限仍由后端校验。

### 3.3 所有权与删除

仓库只有一个 OWNER。OWNER 可以把所有权转给启用账号，并选择自己转移后的权限；同一目标 OWNER 下名称冲突时必须同时解决新名称。

当前账号停用流程没有实现“批量接管其全部仓库”的完整事务能力，因此停用仍拥有仓库的账号前应先逐个转移所有权。

删除仓库会先从正常列表隐藏并登记清理，再由后台任务删除受管目录和派生数据。本地 Git 的原始目录不会被平台删除。

### 3.4 准备项目与查看画像

在仓库列表点击“准备 / 画像”可查看当前仓库的四阶段准备轨道。拥有 MAINTAIN 权限时，点击“开始准备”会依次刷新代码快照、生成内容与向量索引，并在内容就绪后构建当前快照的 CodeGraph。

内容索引和 CodeGraph 构建进入后台队列后都可以关闭页面；再次打开项目画像即可查看状态并继续后续阶段。CodeGraph 缺失或执行失败不会阻止源码浏览和关键词问答。

项目画像展示当前已发布快照的文件数量、语言构成、一级目录、常见入口文件、代码片段、向量覆盖、知识卡片及图谱规模。它不调用模型，也不把推测结果标记为架构事实。画像底部可直接进入源码检索、调用图谱或知识问答。

## 4. 索引任务

“索引任务”页面包含两个 Tab：

- 索引任务：查看仓库准备、同步、内容索引、向量与图谱相关任务；
- 向量索引：查看当前仓库当前快照对应的有效向量状态。

页面顶部不重复显示“索引任务”内容标题，Tab 与内容区使用和账号管理、系统设置一致的贴合样式。向量索引页使用全局当前仓库，不在页内重复提供仓库切换，也不展示“当前生效向量索引，仅展示快照”这类无操作价值的说明。

任务支持排队、运行、成功、失败、取消和重试等状态。`INCREMENTAL` 目前只是任务类型枚举，不能据此宣称已实现完整的 Git diff 增量索引；当前验收仍以仓库当前发布版本形成一致索引为准。

不同任务产生的向量通过仓库、代码版本、索引版本和向量模型标识隔离。用户查询只使用当前发布版本；历史任务保留作审计，不参与当前检索。

## 5. 源码检索与预览

菜单名称统一为“源码检索”。页面支持在当前仓库内按路径、符号和正文关键词查找代码切片，并查看文件、符号、行号和匹配内容。

打开结果后可预览源文件：

- 普通文本按 UTF-8 解码并高亮；
- Markdown 文件提供源码/渲染预览，渲染内容经过消毒；
- `.bat`、`.cmd` 在 UTF-8 解码失败时回退 GB18030；
- 目录、路径越界、含 NUL 的二进制文件和超过 2 MiB 的文件被拒绝。

源码预览只用于阅读，不提供在线编辑、保存或提交代码能力。

## 6. 知识问答

在顶部选择当前仓库后进入“知识问答”，页面会检查仓库准备状态并加载已备案的问答模型。先在页面顶部选择一个检测可用的模型，再输入问题。系统只对当前仓库执行代码和已发布知识联合检索，回答会展示命中的文件、符号、行号和引用，便于回到源码复核。

每轮回答下方可展开“检索诊断”，查看实际快照、向量模型、成功启用的通道、融合召回数量和耗时。任一检索通道失败时会列出不可用通道、稳定原因代码和错误摘要，不应把降级回答理解为完整能力下的结果。

### 6.1 回答路径

| 条件 | 实际结果 |
| --- | --- |
| 有证据 + 已选择检测可用的模型 | 调用所选 OpenAI-compatible 模型生成回答 |
| 未选择模型或所选模型检测不可用 | 阻止发送并提示选择可用模型 |
| 模型调用过程中失败 | 返回本地证据型回答并记录模型运行状态 |
| 没有足够检索证据 | 明确提示证据不足，不编造结论 |

问答模型不再使用全局启用状态和代码外发开关。每次请求明确携带当前页面选择的模型；代码证据中的密码、Token、API Key 和私钥内容会先脱敏再发送。

历史记录按会话展示，支持恢复整段多轮问答、重命名和删除。追问会携带最近上下文用于检索消歧和回答生成；当前仍没有流式 Token、停止生成或断线续传。

## 7. 图分析

在“图分析”使用当前仓库构建或重新构建 CodeGraph。接口只把任务加入队列；后台 Worker 复制当前代码版本到独立分析目录，运行 CodeGraph CLI，校验产物后原子发布，不会在冻结源码目录内写入分析文件。任务详情显示心跳、超时截止和失败代码，并可取消。

图谱就绪后可按符号和深度执行影响分析，查看节点、关系边、源码位置、统计和风险提示。代码版本更新后需要为新版本重新构建，旧图谱不会冒充当前结果。

CodeGraph 未安装或任务失败时，图分析不可用，但其他核心功能仍可继续使用。

## 8. 知识沉淀

“知识沉淀”使用知识卡片组织业务规则、技术决策、接口约定和模块说明。卡片分别展示发布状态、人工评审状态和来源版本状态；编辑生成新修订，不覆盖历史版本。

用户可以：

- 新建和编辑卡片；
- 查看修订历史；
- 将历史版本恢复为新的草稿；
- 关联仓库、文件或代码证据；
- 管理当前实现支持的附件。

保存或恢复内容只会形成“草稿 + 未评审”，不会自动发布或自动等价于人工确认。MANAGE 用户需先单独执行人工评审，再单独发布；来源版本“当前”只表示自动核对到当前代码，不表示人工认可内容。来源过期会退出检索，即使卡片仍保留历史发布状态。Markdown 自动生成内容同样保持草稿和未评审。

## 9. 系统设置

系统设置采用与知识卡片统一的卡片、标题、间距和操作区样式，负责问答模型和向量模型备案。

### 9.1 问答模型

管理员可新增多个 OpenAI-compatible 模型备案，维护地址、模型标识、密钥和生成参数：

1. 保存模型；
2. 执行连接检测；
3. 检测成功后，到知识问答页面选择该模型。

问答模型卡片只提供检测和编辑，不再提供“切换使用”或“停用”。不同用户和不同问答请求可以直接选择不同模型。

### 9.2 向量模型

向量模型与问答模型分开备案和切换，支持本地 `LOCAL_HASH` 和 OpenAI-compatible embeddings。本地哈希固定 64 维，只用于字符相似度，不理解同义词、业务含义或代码语义；外部 embedding 才显示为语义检索并支持 1–4096 维。模型卡片会展示实际能力和限制，并可独立检测 `/embeddings`，返回长度必须与备案维度一致。

切换向量模型后，新旧向量通过模型标识和索引版本区分，当前检索不能混用不同模型空间。

## 10. 当前能力边界

当前已形成“仓库接入 → 一键准备/项目画像 → 检索/问答/图 → 知识沉淀 → 管理配置”的基本闭环，但以下能力尚未交付：

- 快速开始或开发者 Onboarding 首页；
- 流式回答、停止生成与断线续传；
- 企业 SSO/OIDC 与多租户；
- 在线代码编辑、提交或 PR；
- 批量 OWNER 接管；
- HTTPS 证书自动签发与轮换（Secure Cookie 已支持部署配置）；
- Qdrant/LanceDB、消息队列或独立 worker。

规划功能必须放入后续版本章节，不得混入当前操作说明。

# 四项交互修正验收

记录日期：2026-10-14。范围：产品建议中的 U1–U4；本次未打包或更新部署镜像。

| 项目 | 修改后的行为 | 验证范围 |
| --- | --- | --- |
| MCP 指南 | 检索和上下文示例跟随当前项目、分支；明确要求 branchId 或 contextId；说明 WORKSPACE 的 UUID、账户绑定及有效期 | 示例在切项目时不会沿用其他项目分支；浏览器展示正确 |
| 问答模式 | 区分未选择、本地证据、指定模型；明确选择后在当前项目/分支的页面会话中保留；已选模型失效时重新推荐 | 连续发送、离开后返回、已选模型失效、推荐弹窗关闭、失败重试 |
| 编辑保护 | 关闭、取消、Esc、离开页面、切项目/分支、刷新上下文或工作区页签前保护输入；浏览器刷新使用原生离开提示 | 继续编辑保留内容；仅明确放弃才关闭；保存/附件上传期间阻止离开；失败后仍保护；重复点击只出现一次确认 |
| 问题跳转 | 概览携带问题类型和分支上下文；知识页清理旧筛选并显示问题条件，可清除 | 缺维护人仅命中强约束且未归档知识；复核问题按当前修订的分支验证筛选，不沿用全局来源状态或旧修订验证 |

明确选择的问答模式使用现有页面内存保存，浏览器整页刷新后重新选择；不向浏览器持久存储写入会话内容。保存知识仍生成草稿，发布权限和确认流程保持原实现。

- 针对性回归：7 个测试文件、50 项测试通过，覆盖问答、知识页、编辑器、概览、工作区切换、路由和 MCP 示例。

- 前端构建：`npm.cmd run build` 通过，包括 TypeScript 检查。保留既有依赖注释、混合导入和大包提示。
- 浏览器：Chrome、1440 × 1000，模拟接口下的 MCP 参数、连续问答、返回问答、编辑取消/Esc、页面离开、问题跳转/清除、列表可用高度均通过，无页面脚本错误。
- 浏览器验收用于验证前端真实组件与导航交互，未替代真实模型、MCP 客户端或后端业务联调。

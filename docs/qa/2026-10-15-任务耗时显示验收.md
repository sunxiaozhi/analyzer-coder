# 任务耗时显示验收

## 范围与口径

- 任务中心的分支任务列表、分支任务详情以及分支管理任务记录增加“耗时（含排队）”。运行中从 `createdAt` 计算至当前时间，终态从 `createdAt` 计算至 `updatedAt`。分支任务已有两个数据库时间字段，本次只补充接口响应，无数据库迁移。
- 任务中心的其他任务列表和详情增加“执行耗时”，以 `startedAt` / `finishedAt` 计算；尚未开始的排队任务显示“排队 …”。取消请求仍在执行时继续计时，终态固定显示。
- 显示秒、分、小时、天；不足一秒明确标注。缺失、无效或倒序时间显示“—”，不推测历史任务用时。
- 计时在前端每秒更新，不新增接口请求。组件卸载或缓存页面隐藏时清理计时器，重新显示时同步当前时间。

## 验证结果

- 前端相关测试：3 个文件、12 项通过，覆盖计时口径、终态固定、取消请求、异常时间、卸载及 KeepAlive 恢复、分支列表与详情。
- 后端相关测试：11 项通过，覆盖历史和最新任务查询的时间映射，以及原有权限、分页、操作接口和错误消息行为。
- 前端 `vue-tsc` 与生产构建通过；两处修改的 Java 文件已按项目 Spotless 规则格式化。
- Chrome 模拟接口验证通过：分支总耗时实时更新及终态固定、列表和详情一致、其他任务执行与排队时长、390px 手机表格滚动；没有页面异常或未匹配接口。
- 浏览器验证使用模拟接口；未替换或重启本地 Docker 后端。分支耗时需要运行包含本次时间字段的后端版本，旧接口下兼容显示“—”。

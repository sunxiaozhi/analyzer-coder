# 任务详情与阶段进度验收

## 本次落实

- 分支任务详情隐藏任务编号、内容版本编号；错误信息末尾由系统追加的同任务编号也隐藏，保留原始接口数据和排障日志。
- 其他任务详情隐藏任务编号；当前阶段在列表与详情转换为中文说明，不展示阶段字符串中附带的内容版本标识。
- 一键准备以同步代码、内容索引、代码图谱三个顺序步骤展示进度。依据数据库最后记录的阶段，标注已完成、执行中、等待执行、失败和后续未执行。
- 单个任务展示执行状态与当前阶段，保留已有耗时展示。
- 任务详情、项目总览等待区、分支管理任务区复用同一进度组件；不增加轮询或改变原有任务操作。
- 历史任务缺少失败阶段时，各步骤标为未记录并说明原因，不推断完成步骤；收尾阶段失败与业务步骤失败分开呈现。

## 验证

- 相关前端测试：5 个文件、34 项通过，包含阶段顺序、失败后已完成步骤保留、旧数据兼容、轮询响应更新、取消与超时、原有耗时及任务操作行为。
- `vue-tsc` 与 Vite 生产构建通过；构建保留既有依赖注释、模块拆分和体积提示。
- Chrome 模拟接口验收通过：详情编号隐藏、复合任务从内容索引执行切换至图谱失败、旧失败任务提示、单任务中文阶段与耗时、390px 手机布局。无页面异常或未匹配接口。
- 桌面及手机截图已检查。

## 范围

本轮只修改前端，不改数据库和后端任务流程；未新增精确百分比、处理数量或每阶段独立耗时。自动拉取代码、Word/PDF 正文解析、服务端分页和流式回答继续暂缓。

已实现的分支总耗时仍依赖上一轮后端新增响应时间字段。本次未更新或重启运行中的 Docker 后端，未调整 VERSION 或打包发布。

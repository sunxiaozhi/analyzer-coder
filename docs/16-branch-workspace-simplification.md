# 分支面板简化与功能承接

## 问题

项目管理的分支面板同时承担分支跟踪、快照管理、索引构建、任务历史、知识验证和检索。版本与刷新入口重复，主要操作不突出。管理选中的分支容易被误认为全局阅读分支。
知识库的人工评审、来源复核与分支验证不是等价操作；直接删除分支验证入口会丢失对知识修订、分支和快照的验证能力。任务中心目前只展示普通索引任务，不能直接替代分支准备任务列表。

## 改造方案

1. 分支面板保留分支选择、同步、一键准备、打开代码与状态摘要。单项索引重建、向量构建、MCP 参数放入更多操作；归档分支默认收起；添加分支与远程发现统一折叠入口。
2. 合并重复版本信息与刷新操作。列表表达管理选择，打开代码才切换全局阅读上下文。显示管理分支与阅读分支的区别。
3. 移除面板内重复检索，通过代码与知识页面检索；保留打开代码图谱入口。
4. 将分支知识验证迁至知识详情，自动定位所查看的知识。保留四种结论、必填说明、管理权限、修订及快照绑定。知识列表展示并筛选当前分支验证状态。保存后刷新阅读上下文和知识，防止旧上下文继续沿用旧结论。人工评审和来源复核继续独立展示。
5. 任务中心新增分支任务视图，以项目和分支筛选，新增分页历史接口，保留现有仅返回最新任务的接口行为。显示任务阶段、状态、错误和快照；提供回到分支管理的入口。未实现的分支取消接口不套用普通任务接口。面板仅展示当前任务摘要与失败原因。
6. 更新组件测试、知识详情测试和功能说明。增加项目读取权限下的分支任务历史查询；无需修改数据库结构，也不删除分支、快照、索引或验证的后端规则。

## 组件边界

- BranchWorkspace：管理分支选择、跟踪和代码操作，组合列表、准备摘要和添加入口。
- BranchListTable：分支及就绪摘要，提供管理选择和归档恢复事件。
- BranchIndexPanel：单份版本摘要、主要动作、折叠高级操作及当前任务摘要。
- KnowledgeBranchValidationPanel：在知识详情中读取和保存该知识针对当前阅读快照的验证结论。
- BranchTasksPanel：在任务中心读取所选项目的分支任务、筛选和展示详情，不改变全局阅读分支。

## 验收标准

- 分支面板不再包含知识正文、验证编辑或检索结果；同步、一键准备和打开代码易于找到。
- 单项重建、添加跟踪、远程发现、归档恢复、MCP 参数均仍可用。
- 查看管理分支不切换阅读上下文；打开代码正确切换分支。
- 知识详情可以查看和记录分支验证；无管理权限不能提交，知识修订或快照变化不能继承旧结论。
- 验证保存后刷新读取上下文及知识；非 Git 项目不显示分支验证。
- 任务中心可查看并筛选分支任务，普通索引任务保持原有取消及重试行为。
- 前端回归、类型检查和生产构建通过，原有后端接口行为及数据库结构保持不变，新增分支任务分页历史接口。

## 实施与验证记录

文档先于代码修改形成，以上改造已落实。主要修改 BranchWorkspace、BranchListTable、BranchIndexPanel、RepositoriesM0View 和知识详情/列表；验证组件迁至知识功能目录；新增 BranchTasksPanel，并调整任务中心导航及读取权限。后端仅增加 BranchPreparationJobs 历史分页查询与对应控制器入口。

前端 32 个测试文件的 126 项测试全部通过（全量回归发现的旧管理员路由断言更新后单独复测通过）；最终类型检查和生产构建通过。后端相关回归 7 项通过、1 项数据库集成测试因环境条件跳过；后端运行包构建通过。未修改数据库结构。

分支面板展示运行中任务或当前快照的失败摘要，完整历史在任务中心。分支任务尚无取消接口，因此不提供取消按钮；失败任务可回分支管理重新提交对应操作。普通索引任务仍保留既有取消及重试能力。


运行验证：更新后的后端与前端页面均返回 HTTP 200，直连和前端代理健康检查均正常。实际账号密码已不同于初始化配置，未继续尝试登录；带会话的分页历史接口未做线上实测，权限与参数边界由后端测试覆盖，分页和分支筛选交互由前端测试覆盖。
